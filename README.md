# Abubakar Usman — Portfolio (Next.js)

This is a Next.js (App Router) conversion of the original TanStack Start /
Vite project generated by Lovable.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## What changed from the original project

- **Routing**: TanStack Router's `src/routes/__root.tsx` + `src/routes/index.tsx`
  became `app/layout.tsx` + `app/page.tsx` (Next.js App Router). The 404 and
  error boundaries became `app/not-found.tsx` and `app/error.tsx`.
- **Fonts**: Google Fonts are now loaded via `next/font/google` (self-hosted,
  no external `<link>` tags) instead of a `<link rel="stylesheet">` to
  fonts.googleapis.com.
- **Metadata / SEO**: head tags, Open Graph, Twitter card, and the
  `Person` JSON-LD block moved into Next's `Metadata` API and `app/layout.tsx`.
- **Styling**: `src/styles.css` → `app/globals.css`, unchanged otherwise
  (still Tailwind CSS v4 with the same design tokens, `@utility` animations,
  etc.). `postcss.config.mjs` now runs `@tailwindcss/postcss`.
- **Server plumbing removed**: `src/server.ts`, `src/start.ts`,
  `src/router.tsx`, and `src/routeTree.gen.ts` were TanStack Start/Nitro-specific
  and have no Next.js equivalent needed — Next.js handles SSR itself.
- **Client components**: any component using hooks or interactivity
  (`Hero`, `Nav`, `Section`, `TiltCard`, the `use-reveal`/`use-mobile` hooks,
  and the shadcn/ui primitives in `src/components/ui`) now has a `"use client"`
  directive, since Next.js defaults everything to Server Components.
- **Portrait image**: the original referenced a Lovable-hosted asset pointer
  (`portrait.png.asset.json`) that only resolves inside Lovable's editor and
  isn't included in the export. `Hero.tsx` now points at `/portrait.png` —
  **add your own image to `public/portrait.png`** (or update the path).

## Project structure

```
app/
  layout.tsx      – root layout, fonts, metadata, JSON-LD
  page.tsx        – home page (renders all the site sections)
  not-found.tsx   – 404 page
  error.tsx       – error boundary
  globals.css     – Tailwind v4 + design tokens
src/
  components/site – Hero, Nav, Skills, Projects, Contact, etc.
  components/ui   – shadcn/ui primitives
  hooks/          – use-reveal, use-mobile
  lib/            – profile data, cn() helper
public/           – favicon, robots.txt, (add portrait.png here)
```
